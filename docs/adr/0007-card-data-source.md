# ADR 0007: Card data and art source

**Status:** Pending Track B (`docs/research/data-sources.md`)

## Context
The card database needs complete English coverage through OP-17 and ST-31 to ST-36, accurate text, and art with display rights and no SAMPLE watermark, fetched at build time (data) and at runtime (art).

## Decision
To be filled from Track B: primary source, fallback source, exact endpoints, terms relied on and the date they were read.

## Consequences
The image module has one base URL per source, so a terms change is a one-line swap.
