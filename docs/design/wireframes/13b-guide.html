What the deck is trying to do

Rocks is a blue card-advantage midrange deck built almost entirely from OP17 Rocks Pirates SH-XEB. Every leader attack trades one hand card for a reveal that draws two when the top card is Rocks Pirates, so each attack is a two-for-one SH-XEB. It finishes with the 10-cost Rocks.D.Xebec, which draws and plays two more Rocks Pirates from hand CARD.
