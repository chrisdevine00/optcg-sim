## Engine observations (no change made)

- **A choice of "which DON!!" with one class available is still asked.** `rest` over `donCostArea` with `exactly: 1` and 2 or more active DON!! asks the player to pick the class `costActive`, although there is nothing to choose (OP12-018, OP12-037 in the "two DON!!" test). When the count equals the requested number it is automatic. A purely cosmetic prompt; the UI may want to auto-answer a single-class decision. Not changed (semantics belong to the lead).
- **`select` on a hand asks even with no candidate** (hidden pool, so the opponent learns nothing from whether a prompt appears). OP12-015 and ST31-001 behave this way and their tests answer the empty choice.
- `OP12-015` / `ST31-001` / `ST31-005` were not given a mid-turn Rush attack test through given DON!! (the keyword is checked on the derived card instead).
