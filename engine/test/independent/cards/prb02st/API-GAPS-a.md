# PRB-02 / ST-15 / ST-16 / ST-17 (group A): observation and setup gaps

- **G1 (PRB02-002 Law, PRB02-006 Zoro, PRB02-009 Mr.3): the opposing effects used as scenery are few.** Most older Characters and Events have no script (OP-01, OP-03 and most of the Leaders are not scripted, so an unscripted card does nothing when played). The removal and rest effects the tests use are OP09-077 Gum-Gum Lightning (K.O., 6000 or less), EB01-059 Kingdom Come (K.O.), EB03-027 Marguerite (bounce, 7000 base power), OP17-024 Howling Gab (a Character's rest) and OP13-038 Gum-Gum Elephant Gun (an Event's rest). Not covered: a rest paid as a cost (Q41), removal to the bottom of the deck, and removal of Law by one of MY effects (no scripted card K.O.s or bounces my own cost-6 Character on my turn), so Law's "by your opponent's effect" qualifier is pinned only against a battle K.O.
- **G2 (PRB02-008 Marco, ST15-003 Kingdew): the owner's-own-turn K.O. by an effect cannot be produced** with a scripted card that reaches a cost 4 (Marco) from a Leader or Event the owner controls. Kingdew's "[Opponent's Turn]" gate is pinned with ST27-005 Teach (cost 3 or less, any side) K.O.ing it on my own turn. Marco's [On K.O.] is pinned on the opponent's turn (effect and battle) only: an attacker never loses a battle, so no battle can K.O. my own attacking Marco.
- **G3 (PRB02-004 Bonney, PRB02-006 Zoro, PRB02-009 Mr.3): which rested DON!! card is set active is not observable.** DON!! cards are interchangeable in the public API; tests read the counts of the cost area (`queries.don`: active, rested, given, deck).
- **G4 (ST16-003 Katakuri): the rested state of the Leader and Stage is set by the scenario** (`rested: true`); no test rests them through play, so the "becomes rested during the turn" path is only covered for DON!! (cost payment) and Characters (attack, block).
- **G5 (PRB02-010 Pudding): the DON!! -2 cost pick** is answered with rested DON!! (`payDon(..., 'costRested')`); the engine asks which class to return because both active and rested DON!! exist. A position with one class only would pay without a question; the tests do not depend on it.
