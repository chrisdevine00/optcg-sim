# OP-14 group A: observation and setup gaps

- **G1 (OP14-023 Kikunojo): the "[End of Your Turn]" gate cannot be probed on the opponent's turn.** The effect is only for my own End Phase. Resting Kikunojo on the opponent's turn and looking at it before my next Refresh Phase is not possible: the Refresh Phase runs inside `endTurn`, so the test would see it active either way. Tests pin the own-turn behaviour (rested, attacked, two copies, other Characters untouched, not attackable afterwards) only.
- **G2 (OP14-021, OP14-027, OP14-028, OP14-032): "becomes rested" through a cost or an effect on my own turn cannot be separated from resting by attack.** The only way a test can rest its own Character in the Main Phase without attacking is a cost such as OP14-029 Tashigi's "rest 2 of your cards", which would need an answer to open question M6b-Q30 to assert. The tests use attacking as the "becomes rested" event and assert the [Your Turn] gate with an opposing effect (OP17-038).
- **G3 (OP14-024 Kin'emon): "you cannot play Character cards during this turn" is tested against playing from hand only.** No scripted card in the tested sets plays a Character by an effect during my own Main Phase after Kin'emon's On Play without also being a Character card itself, so the "by an effect too" reading is untested.
- **G4 (OP14-016 X.Drake, OP14-029 Tashigi, OP14-034 Luffy): only removal by K.O. is exercised.** The replacements also cover "removed from the field" (bounce, bottom of deck, trash) for X.Drake and Tashigi; no opposing bounce or bottom-deck effect used as scenery was scripted at test time, so only K.O. by effect (OP09-077 Gum-Gum Lightning, EB01-059 Kingdom Come) was used.
- **G5 (OP14-034 Luffy): one rest saving two Characters K.O.'d at once is untested.** QA-OP17 for OP17-023 Nami (same shape of text) says one rest saves both; no group-A test sets up a simultaneous double K.O. with the shared [Once Per Turn] use because the readings of the shared use are not settled (M6b-Q6).
- **G6 (OP14-005 Killer, OP14-012 Bepo): "give rested DON!!" has no way to read which DON!! card moved.** DON!! cards are interchangeable in the public API; tests read the counts in the cost area (`queries.don`: active, rested, given).
