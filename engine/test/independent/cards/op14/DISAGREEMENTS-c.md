# OP-14 group C: disagreements with the scripts

Cards OP14-062 to OP14-086 (23 cards). The independent tests were written from the verified card text and the rules only.

**None.** Every test in `OP14-062` .. `OP14-086` passes against the scripts; no `it.fails` was needed.

Open questions the tests deliberately avoid deciding (they assert only what every reading shares):

- M6b-Q45, OP14-065 Senor Pink: "your opponent returns 1 DON!!" with fewer than 1 DON!!: only "nothing happens and nothing is asked" is asserted.
- M6b-Q30 / Q41, OP14-070 Buffalo: only the Blocker's own block (never counts) and an opposing Character's effect (counts) are asserted. A rest as a cost or from a Leader effect is not (OP06-021 Perona is not scripted, so the Leader case could not be played anyway).
- RL-11, OP14-082 Oinkchuck: "until the end of your opponent's next End Phase" created on the opponent's own turn is asserted to end at that turn's End Phase (back to the printed cost on my next turn), following RL-11 (ends at step 6-6-1-2 of the opponent's End Phase). A reading in which "next" skips the current End Phase would differ.
