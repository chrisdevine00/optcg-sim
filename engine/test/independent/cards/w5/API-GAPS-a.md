# API gaps, wave 5 group A

- G1. EB03-033 Brulee, "by your effect": no scripted card makes an opponent's effect return MY DON!!, so "returned by the opponent's effect does not count" is untested. The positive tests use EB04-030 Kaido's printed replacement ("return 1 DON!! instead of the K.O."), which is an effect and not a cost, so every reading of M6b-Q65 agrees. The cost route (a [Counter] DON!! -1) is asserted only on the bounds both readings share (at most 1 DON!! added, rested, no active DON!!).
- G2. EB03-033 Brulee: "[Opponent's Turn]" with a DON!! -N that I pay is only reachable through a [Counter] Event (OP07-076); there is no cheap Character or Leader that returns DON!! by an effect on the opponent's turn.
- G3. OP09-065, OP09-119, OP09-070, OP09-076: "an optional cost that cannot be paid" cannot be built. Each card costs 3 or more and the DON!! rested to play it stay on the field, so at least 3 DON!! can always be returned. OP09-068 (Chopper) and OP09-073 (Brook), which are not paid for on play, do have the unpayable case tested.
- G4. OP09-025 Crocodile ("ODYSSEY") and OP09-104 Sabo ("Revolutionary Army"): the data prints the official exact `{X}` type as `"X"`. The exact-versus-substring difference is untestable: no card in the pool has a type that merely contains "ODYSSEY" or "Revolutionary Army" (the Leader OP09-022 Lim is the only ODYSSEY card, and every Revolutionary Army card has exactly that type).
- G5. OP03-008 Buggy: "in any order" for the 5 cards placed at the bottom. The order the player picks is not observable beyond the set of cards at the bottom (tests answer any `order` decision with the first listed order and assert the set). Also untested: a K.O. by the EFFECT of a Slash-attribute card (no cheap scripted Slash card K.O.s a Character by an effect); K.O. by an Event is covered.
- G6. EB02-035 Sanji & Pudding and OP09-061: whether the [Once Per Turn] is spent when the player answers 0 to "add up to 1" is not asserted (the text does not settle it).
- G7. OP09-104 Sabo: a face-up Life card's own [Trigger] (a Revolutionary Army Character with a [Trigger] added face-up, then hit) is not tested.
